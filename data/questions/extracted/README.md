# Extracted questions

Records transcribed from licensed source material go here, with `"origin": "extracted"`,
`sourceImages` listing the screenshot IDs (S001–S230, see `source/screens/inventory.json`),
and honest `contentVerificationStatus` / `answerVerificationStatus` values.

This folder is intentionally empty: the supplied screenshots come from a commercial,
subscription question bank carrying a per-subscriber watermark, so their questions were
not reproduced. See `docs/extraction-report.md`.
